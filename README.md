# custo3d-dados

Arquivos **públicos** usados pelo app Custo 3D. O código do app fica em outro repositório, privado.

- `privacidade.html` / `privacy.html`: política de privacidade (link exigido pela Play Store)
- `dados/tarifas.json`: tarifas da ANEEL, atualizadas toda segunda pelo robô `.github/workflows/tarifas.yml`
- `config.json`: links de afiliado do botão "Comprar filamento" (edite e salve; o app atualiza em até 1 hora)
